Data Source and Update Method

This page is an original dashboard and is not a copy of the Next Spaceflight website. The initial entries below were transcribed from the Cape Canaveral entries visible on Next Spaceflight’s public launches index on 13 November 2026.

To update it, edit the LAUNCHES array near the bottom of this file with data you are authorized to publish. Do not depend on browser-side scraping of another website: it can fail because of cross-origin controls and may require the source owner’s permission or an approved API/license.

All precise launch times should be stored as ISO-8601 UTC values in windowUtc. If an official time is not confirmed, leave windowUtc blank and populate scheduleText; the dashboard will display it as timing TBD rather than infer a Zulu time.
